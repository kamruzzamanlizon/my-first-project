## Example wording

"Thanks for completing this batch. I noticed that some objects in the reviewed items were assigned a class that does not match the project definition. Please compare those cases with the class examples in the guideline and correct the affected labels. If you find an object that remains ambiguous, flag it for review rather than guessing. I will check the corrected sample before the next batch."

## Feedback principles

- Describe the observed issue, not the person.
- Point to a specific example or guideline section.
- Explain the expected correction.
- Distinguish a confirmed error from an ambiguous case.
- Record repeated patterns so coaching can address the root cause.
