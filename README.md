## Working principles

1. Follow the project’s written annotation guidelines.
2. Apply consistent review criteria across annotators.
3. Record issues clearly and provide actionable feedback.
4. Escalate ambiguous cases instead of guessing.
5. Track recurring errors and use them to guide coaching.
6. Protect client data and follow confidentiality requirements.
